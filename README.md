# My Expense Tracker 🐣💰

แอปจัดการรายรับ-รายจ่ายสุดน่ารัก สร้างด้วย React + Vite + TailwindCSS + Recharts

## ✨ ฟีเจอร์
- 📅 เลือกดูข้อมูลรายเดือนและรายปี (2024-2025)
- 💛 Dashboard สรุปยอด รายรับ, รายจ่าย และยอดคงเหลือ
- 📊 กราฟแท่งแสดงรายรับ-รายจ่ายในแต่ละวัน
- 🥧 กราฟวงกลมแยกหมวดหมู่รายรับและรายจ่าย
- 🧸 ข้อมูลจำลอง (Mock Data) ที่สมเหตุสมผล
- 📱 รองรับการใช้งานบนมือถือและคอมพิวเตอร์

## 🚀 วิธีการรันโปรเจกต์

1. **ติดตั้ง dependencies:**
   ```bash
   npm install
   ```

2. **รันโปรเจกต์ในโหมดพัฒนา (Development):**
   ```bash
   npm run dev
   ```

3. **เปิดเบราว์เซอร์:**
   ไปที่ `http://localhost:5173` (หรือพอร์ตที่แสดงใน terminal)

## 🎨 เทคโนโลยีที่ใช้
- **React** (Vite)
- **TailwindCSS** (Styling)
- **Recharts** (Charts)
- **Lucide React** (Icons)
- **date-fns** (Date manipulation)
